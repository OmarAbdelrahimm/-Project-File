# ملف المشروع | ProjectFile_System_Repo

مستودع العمل لقناة **ملف المشروع**، لإنتاج حلقات يوتيوب تعليمية هندسية باللغة العربية، تتراوح مدتها من 3 دقائق إلى ساعة، ثم استخراج مقاطع **Shorts** من الحلقات الطويلة.

يُحفظ هنا كل ما هو كود أو نص أو إعدادات، مع تنظيم ملفات الحلقات مستقبلًا داخل `data/projects/` بمعرّفات مثل `CASE_001` و`CASE_002`، وملفات الهوية ضمن `brand/`.

أما الفيديوهات والصور النهائية وحزم النشر والوسائط الخام، فتُسلّم عبر Google Drive فقط ولا تُودع في هذا المستودع.

## تعليمات استلام صفحات HTML التفاعلية

حمّل ملف HTML وافتحه محليًا في المتصفح؛ معاينة Google Drive لا تشغّل JavaScript بكامل وظائفه، لذا لا تصلح للتحقق من التفاعل.
