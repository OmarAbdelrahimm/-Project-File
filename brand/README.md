# Brand source of truth

- `BRAND_BOOK.md`: official Brand Kit v3 standards.
- `colors.json`: canonical color palette.
- `assets/`: editable SVG source files only. Final PNG/video renders are distributed through Drive, not Git.
- `src/`: generators, page source, and Remotion React compositions.
- `motion/`: the approved intro's composition and codec/export settings.

For HTML approvals, download the file and open it locally; the Drive preview does not execute JavaScript fully. No CASE_001 content belongs here until its separate brief is received.
