# Brand source of truth

- `BRAND_BOOK.md`: official Brand Kit v3 standards.
- `colors.json`: canonical color palette.
- `assets/`: editable SVG source files only. Final PNG/video renders are distributed through Drive, not Git.
- `src/`: generators, page source, and Remotion React compositions, including CASE_001 review renders.
- `motion/`: the approved intro's composition and codec/export settings.
- `THUMBNAIL_SEO_STANDARDS.md`: mandatory before designing, editing, or exporting every thumbnail.
- `THUMBNAIL_PROMPT_BUILDER.md`: prompt workflow and source-choice guidance for thumbnails.

For HTML approvals, download the file and open it locally; the Drive preview does not execute JavaScript fully.
